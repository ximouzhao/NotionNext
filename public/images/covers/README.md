# Article Covers

Store final, reviewable Notion article Covers here.

- Filename: `cover-<slug>.png`
- Preferred size: `2400×800` (3:1)
- Keep important content inside a centered, crop-safe horizontal band.
- Keep the final file in the intended repository change set; commit it only when the user explicitly asks.
- Upload the same file to Notion with `.cursor/skills/upload-notion-cover/SKILL.md`.

Do not store API tokens, temporary signed URLs, or intermediate generation files here.
